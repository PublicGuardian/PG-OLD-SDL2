# Public Guardian
A game where you're Big Brother.

## Warning about this code
Do **not** leak the source code for this game.

## How to set this up
You will need .NET Core 5.0 or higher (currently tested on 5.0.202).

For now, you'll need to first copy the files in "Assets" into the folder where the executable is.

Then, to build without executing:
```
dotnet build
```

To build and run automatically:
```
dotnet run
```

You may need to [download SDL2 first](https://www.libsdl.org/download-2.0.php).
